Instalacja TermoJastrych na telefonie (PWA)

Wymagana do otrzymywania powiadomień Web Push na iPhone oraz dla ikony na pulpicie.

iPhone / iPad (Safari, iOS 16.4+)

1. Otwórz stronę bezpośrednio w przeglądarce Safari.

2. Dotknij ikony Udostępnij (kwadrat ze strzałką w górę).

3. Wybierz Dodaj do ekranu początkowego i zatwierdź.

4. Uruchom TermoJastrych z nowej ikony na pulpicie i włącz Web Push.

Android (Edge, Chrome lub Opera)

1. W Edge / Chrome dotknij menu (≡ lub ⋮) i wybierz Dodaj do telefonu / Zainstaluj aplikację.

2. W Operze dotknij menu ⋮ i wybierz Ekran główny / Zainstaluj (włącz też zgodę na powiadomienia bez blokady reklam dla tej strony).

3. W ustawieniach Androida (Aplikacje → Edge/Opera → Bateria) ustaw Bez ograniczeń, aby telefon nie usypiał powiadomień Push w tle.

Instalacja TermoJastrych na własnym serwerze Proxmox VE (LXC)

Pełna instrukcja uruchomienia 24/7 z serwerem Web Push (VAPID) i HTTPS dla Androida (Edge / Opera).

Ważne dla Androida (Edge / Opera): Powiadomienia Web Push oraz instalacja PWA wymagają bezpiecznego adresu HTTPS. Otwarcie strony po samym http://192.168.x.x:4000 zablokuje rejestrację powiadomień push.

1. Utworzenie kontenera LXC w Shellu hosta Proxmox (z obsługą Tailscale)

W Proxmox Node → Shell utwórz kontener Debian 12 (np. ID 120) i włącz /dev/net/tun:

pveam update
TEMPLATE=$(pveam available --section system | awk '/debian-12-standard/{print $2; exit}')
pveam download local "$TEMPLATE"
pct create 120 "local:vztmpl/$TEMPLATE" --hostname termojastrych \
  --cores 2 --memory 2048 --swap 512 --rootfs local-lvm:8 \
  --net0 name=eth0,bridge=vmbr0,ip=dhcp --features nesting=1 --unprivileged 1
printf 'lxc.cgroup2.devices.allow: c 10:200 rwm\nlxc.mount.entry: /dev/net/tun dev/net/tun none bind,create=file\n' >> /etc/pve/lxc/120.conf
pct start 120 && pct enter 120

2. Instalacja Node.js 22, wgranie plików i budowanie w LXC

Najpierw pobierz kod projektu (przez git clone z GitHuba albo rozpakuj paczkę .zip do /opt/termojastrych):

apt update && apt install -y curl git unzip
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
mkdir -p /opt/termojastrych
# wariant A (GitHub): git clone URL_REPO /opt/termojastrych
# wariant B (ZIP):    unzip /root/projekt.zip -d /opt/termojastrych
cd /opt/termojastrych && npm install && npm run build

3. Stałe klucze VAPID i plik /opt/termojastrych/.env

Wygeneruj klucze poleceniem npx web-push generate-vapid-keys (lub w zakładce Powiadomienia) i zapisz w .env:

PORT=4000
VAPID_PUBLIC_KEY=WKLEJ_KLUCZ_PUBLICZNY
VAPID_PRIVATE_KEY=WKLEJ_KLUCZ_PRYWATNY
VAPID_SUBJECT=mailto:twoj@email.pl

4. Usługa systemd 24/7 (/etc/systemd/system/termojastrych.service)

[Unit]
Description=TermoJastrych PN-EN 1264-4 + Web Push Server
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/termojastrych
EnvironmentFile=/opt/termojastrych/.env
ExecStart=/usr/bin/node /opt/termojastrych/dist/app/server/server.mjs
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

systemctl daemon-reload && systemctl enable --now termojastrych

5. Prywatny HTTPS wyłącznie przez Tailscale (bez otwierania portów)

curl -fsSL https://tailscale.com/install.sh | sh
tailscale up
tailscale serve --bg 4000

Użyj tailscale serve (nie funnel), a w panelu Tailscale włącz MagicDNS i HTTPS Certificates. Otwórz w Androidzie (Edge / Opera) prywatny adres https://termojastrych.twoja-siec.ts.net, zainstaluj jako PWA, ustaw Bateria → Bez ograniczeń, a w stopce kliknij Usuń dane testowe / demo. Pełna wersja znajduje się w pliku INSTALL_PROXMOX.md.
